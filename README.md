# Aethelgard 3D — mundo explorável e editor

Jogo e editor de mapas 3D em Three.js, inspirado no atlas de Aethelgard fornecido pelo autor.

**Desenvolvimento:** `npm install && npm run dev`. **Testes:** `npm run check`.

Personagem 3D low-poly com mochila e espada, controles WASD/setas, Shift (correr), Espaço (pular), clique para rota A*, câmera em terceira pessoa e joystick para dispositivos móveis.

O terreno é uma reconstrução aproximada do atlas, com mar, ilhas, cordilheiras, desertos e florestas. No modo Editor é possível modificar o relevo, pintar biomas, colocar locais, desfazer/refazer e importar/exportar dados. As posições e alturas podem ser corrigidas manualmente.

A ilustração original foi fornecida pelo usuário e não deve ser reutilizada por terceiros sem autorização.
